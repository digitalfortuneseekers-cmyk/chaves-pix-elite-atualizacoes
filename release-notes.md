# Elite 1.7.0

- Aviso de nova versão durante o uso, com consulta a cada minuto e ao voltar para a tela.
- Aviso com novidades e ação de atualização, sem recarregamento automático nem interrupção dos lançamentos.
- No navegador, a ação carrega a nova versão web. No Windows, oferece o executável oficial.
- Cadastro de várias chaves Pix para o mesmo banco em uma única operação.
- Linhas adicionais com detecção automática do tipo, remoção e validação de duplicidades.
- O limite de cinco chaves por banco é mantido. Todas as linhas são validadas antes do salvamento conjunto.

Atualize o Windows para 1.7.0 para receber as novas verificações durante o uso. Na versão web, recarregue a página uma vez.
