# Elite 1.6.0

- Aplicativo Windows com login, keys de acesso e conta master.
- Sincronização financeira por usuário entre computador e celular.
- Proteção contra conflitos, indicação de envio pendente e cópias de recuperação.
- Controle de bancos, chaves Pix, cartões, lançamentos e anotações.

Antes de usar o celular com seus registros atuais, abra esta versão no Windows, entre na mesma conta e aguarde a indicação Sincronizado.

Para atualizar o Windows, feche o aplicativo e execute o arquivo baixado. Seus dados e seu acesso são mantidos conforme as regras do sistema.
