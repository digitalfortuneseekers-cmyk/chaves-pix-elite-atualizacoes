# Elite · Atualizações oficiais

Este repositório distribui as versões públicas do aplicativo Elite para Windows. O repositório de desenvolvimento permanece privado. Não são publicados dados financeiros, senhas, keys de acesso ou backups de usuários neste canal.

## Download

[Baixar a versão mais recente](https://github.com/digitalfortuneseekers-cmyk/chaves-pix-elite-atualizacoes/releases/latest)

[Abrir o aplicativo web e instalar no celular](https://elite-financeiro-mobile.humorouseave4.chatgpt.site)

O acesso ao sistema exige conta autorizada e key válida. Baixar o executável não libera acesso aos dados.

## Atualização no Windows

O aplicativo consulta as Releases públicas deste repositório. Ao encontrar uma versão superior, mostra um aviso com o link do executável. Feche o aplicativo e execute o arquivo da nova versão para concluir a atualização. O download não instala automaticamente.

Na configuração do aplicativo, o canal é `digitalfortuneseekers-cmyk/chaves-pix-elite-atualizacoes`.

## Publicação

O fluxo `Publicar atualização` valida a versão, o hash SHA-256 e o executável preparado em downloads/, e publica a Release correspondente quando esses arquivos são atualizados na branch main. O código do aplicativo não é compilado neste repositório.

Cada versão publicada deve receber um número novo. Não substitua executáveis de versões já publicadas. Atualize release.json, downloads/SHA256SUMS.txt, o executável e release-notes.md juntos.

A transferência dos executáveis do projeto privado para este canal é uma etapa separada. O token padrão do GitHub Actions não concede acesso a outro repositório; não inclua tokens ou senhas nos arquivos públicos.
